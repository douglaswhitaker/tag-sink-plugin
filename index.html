The marker tag identifies which file is the "tag-sink" for a folder. Apply it to a file (any file) in Eagle the normal way, and Sync will aggregate every other tag in the folder onto that file. If no file in the folder has this tag, Sync creates a small blank placeholder image and applies it there. Use "Add File Types to Files" separately to add each file extension (such as csv, xlsx, or pdf) as a tag. If "Include subdirectories" is enabled, Sync walks all descendants, creates a tag-sink in folders that lack one, syncs children first, and then gives the parent sink the union of tags from the entire subtree. When a new sink is needed, the plugin uses a uniquely context-marked image, then an image whose filename matches the folder name, then the folder's only image if there is exactly one; otherwise it creates a blank placeholder. The sink is also named after its folder. In recursive mode, the selected/root folder uses the Marker tag, while sinks in subdirectories use the Marker tag plus "-subdir" (so the default child marker is "tag-sink-subdir"). Existing child sinks from earlier versions using the old "tag-sink" marker are migrated automatically.
